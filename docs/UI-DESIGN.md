# Crossbow B 版界面规范

本次采用用户确认的 **Frame Studio** 布局与平衡冷灰深色主题，关联 #149。布局改动保留已有 IPC、通知队列、配置与 VPN 生命周期。

## 导航与功能

- 桌面一级导航：连接、节点、监测、配置、设置。
- 连接：真实内核状态、当前出口、独立系统代理 / TUN 开关、路由模式、实时流量和本次累计。
- 节点：左侧策略组，右侧地区 / 搜索 / 可用性 / 延迟筛选、单节点和整组测速；底部站点连通性。超时与未测速分开表达。
- 监测：连接、日志、诊断；保留连接虚拟列表、进程聚合、日志跟随和诊断修复。
- 配置：来源、覆写链。来源使用列表与详情布局；URL / 文件导入统一入口，仍支持拖拽。覆写保留创建、启用、绑定、校验与应用。
- 设置：网络与内核、外观、日志、应用与更新。通知 / 托盘的旧页面标识保持兼容，更新入口定位到应用与更新。
- iOS：原生连接、配置、诊断三页。导入仍只支持本地 sing-box JSON，连接或切换中禁止替换配置，不增加尚未实现的订阅与测速入口。

## 颜色角色

| 角色 | 浅色 | 深色 |
|---|---|---|
| 窗口框架 | `#EEF0F5` | `#121317` |
| 内容底色 | `#FFFFFF` | `#1A1C21` |
| 面板 | `#F7F8FB` | `#23262D` |
| 抬高 / 悬停 | `#F0F2F7` | `#30343D` |
| 主文字 | `#242B37` | `#E9EBF1` |
| 次文字 | `#596777` | `#ADB2BE` |
| 强调 | `#455AB5` | `#B7B4ED` |
| 成功 | `#267659` | `#8ACDAF` |
| 浮层 | `#FFFFFF` | `#2A2E36` |

iOS 使用动态语义角色，背景采用窗口框架色，列表面板采用面板色；随系统切换外观。桌面继续支持浅色、深色和跟随系统。强调色用于图表、焦点与选择；面板以明度分层，不使用装饰渐变或发光效果。

## 交互与适配

桌面内容区左右留白 32px；策略列表 184px，间隔 28px；窄窗口逐级缩小，表格只在自身容器横向滚动。按钮有 hover / 键盘焦点；弹窗支持 Escape、Tab 焦点循环和关闭后焦点恢复。通知继续使用统一 Notification，不引入私有 toast。

iOS 使用 NavigationStack、TabView、系统文件选择器与动态字体；主要操作触控区域至少 44pt。页面限制阅读宽度并可滚动，适应 iPhone、横屏和 iPad。底部栏保留当前 iOS 原生呈现。

## 验证与验收

- `npm run build --prefix apps/desktop`。
- `cargo test --lib --manifest-path apps/desktop/src-tauri/Cargo.toml`。
- `swift test --package-path apps/ios`。
- `scripts/ios/build-app.sh --simulator`。
- 浏览器隔离 IPC 数据检查真实 React 页面深浅色、1440 / 1100 / 900 / 720 宽度、旧通知跳转、导入弹窗与独立接管开关。模拟数据只注入临时浏览器，不进入发布代码。
- 真实联网由用户验收：切换节点、测速、代理 / TUN 启停、日志、配置与更新入口；iOS 重连、锁屏与网络切换继续按既有测试流程。

## 编辑与运行

源稿为生产 React 组件和主题样式，`source.zip` 保存本轮修改快照。此目录原型直接引用仓库生产 App；mock-tauri.ts 只替换 IPC，不启动真实代理、不访问用户订阅。不要把该模拟边界打入发布产物。

```sh
npm install --prefix apps/desktop
apps/desktop/node_modules/.bin/vite --config docs/designs/2026-11-04-ui-polish/v01/vite.config.mts
```

- 日志与每秒四次流入：`http://127.0.0.1:5214/?page=logs&stream=1`
- 深色英文日志：`http://127.0.0.1:5214/?page=logs&stream=1&dark=1&en=1`
- 首页：`http://127.0.0.1:5214/`；通过正式导航打开设置→应用与更新或配置→覆写链。
- 检查更新模拟等待 1.2 秒，测试加载中焦点；真实更新与安装不会执行。

## 验收场景

1. 鼠标检查更新：按钮进入等待/完成，无整行框；键盘 Tab 操作仍有控件焦点；通知定位端口/更新/开关对应可操作控件。
2. 设置页面滚动条位于内容对齐线右侧，880×560、1120×720、1440×960 无横向溢出。
3. 日志多选默认三项；可单独增减、全不选、再恢复；菜单保持打开，勾选在右，明暗/中英和键盘仍一致。共享单选消费者行为不变。
4. 鼠标停在日志数据区、复制、Tab 聚焦后保持可见行稳定；后台继续收集；离开时恢复原跟随模式；手动暂停不因离开而恢复。
5. 覆写侧栏不重复标题。常规首页按钮/图表间距 12px，短窗口 8px/96px 图表；整体高度上限仍 700px。

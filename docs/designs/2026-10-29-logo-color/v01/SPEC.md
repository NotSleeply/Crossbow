# B1 Logo 主色微调 V1

- 日期：2026-10-29；状态：配色提案，待用户选择；Issue #202。
- 基线：main / v0.11.3 tag 对应提交 110c7f73fca72ffa3071e8507f0b87f64332f4d5。
- 输入：用户提供实际 Dock 图标截图，感觉颜色偏淡，希望更深一点、更亮一点。
- Skill：logo-generator，使用 Phase 3 的定向色彩精修；不重新生成造型。

## 设计范围

沿用 design/logo/current/mark.svg 和 app-icon.svg 的 B1 原始路径、11 单位笔画、圆角端点、箭头比例、0.74 图标缩放及 #F7F8FB 底色。三种方案只替换 SVG 根元素的 color；6 个 SVG 与母版已按去除 color 后逐字相等校验。

| 方案 | 色值 | 意图 |
| --- | --- | --- |
| A / 当前色 | #455AB5 | 对照，柔和略偏灰 |
| B / 推荐 | #3F52CF | 压低少量红绿通道，提高蓝色纯度；比当前略深、视觉更鲜明 |
| C / 再浓一档 | #3448D8 | 更高饱和度，小尺寸更醒目，存在感更强 |

B 的 HSL 饱和度约 60%，当前约 44.8%；相对亮度由 0.1191 略降至 0.1160。亮度变化很小，主要通过色彩纯度减少灰淡感。没有增加渐变、发光或不透明度效果。

## 预览

- 同时比较品牌组合、应用图标、22/32/48px 小尺寸。
- 下方 Dock 场景固定保留当前图标，右侧随选择切换；暖灰背景只是尺寸与色彩示意，不模拟 macOS 系统材质。
- 浅色/深色品牌组合使用同一选定蓝色，沿用用户此前的同色偏好。
- 窄窗口保留三档图标并排，避免只能看到单个方案而无法比较。
- 切换按钮有 aria-pressed，场景标题使用 role=status，支持键盘焦点与减少动效偏好。

SVG/网页能验证源文件颜色与小尺寸辨识度，实际 Dock 仍受系统渲染、显示器及周围颜色影响；未把网页示意当作已安装真机结果。当前未修改正式应用、官网或 iOS 资产，也未改动发版内容。

## 文件与复现

- generate.py：从正式母版生成三档 mark / app-icon SVG 与 variants.json。
- index.html / style.css / preview.js：可编辑交互展示。
- assets/：六个 SVG。
- previews/：真实浏览器截图与 DOM 检查，覆盖 1120px、390px、切换同步及无横向溢出。
- manifest.json：输入、基线、文件清单和哈希。

运行：
    python3 docs/designs/2026-10-29-logo-color/v01/generate.py
    python3 -m http.server 5202 --bind 127.0.0.1 --directory docs/designs/2026-10-29-logo-color/v01

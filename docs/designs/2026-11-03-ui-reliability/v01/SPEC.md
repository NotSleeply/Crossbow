# 桌面基础交互与连接状态卡片 v01

状态：已实现，待 PR 评审。关联 Issue #271。基线 main：c0aea84。

## 用户确认的范围

处理审计截图中除红框「节点延迟的测量时间」以外的九项问题。后续反馈合入同一实现：连接状态区不放验证按钮，并替换右侧与顶部重复的配置卡片。

| 原状态 | 实现后 | 原因 |
| --- | --- | --- |
| 页面按速率积分，切页后本次累计归零 | 读取内核 connections 快照累计值；标注「内核累计」及内核启动统计口径 | 页面生命周期不再决定累计数值 |
| 状态读取失败可能回退成已停止/关闭 | 失败不覆盖已有成功值；初次读取显示待确认；禁止基于未知值操作接管开关 | 区分无法读取与真实关闭 |
| 运行中暗示整体联网 | 右侧连接状态卡片分别列出内核进程、接管配置、网络连通性 | 不从进程和开关推断互联网可用 |
| 端口失焦自动应用 | 显式应用/回车、取消修改、十进制范围校验、应用中禁用 | 避免点击别处触发内核重启 |
| 节点加载/失败/未配置/内核未就绪混为一谈 | 独立空态及重试/导入/启动动作 | 操作与真实原因对应 |
| 筛选无结果重复提示 | 单一空态及「重置筛选」 | 方便恢复列表 |
| 连接缺失内存/时间冒充零，长连接仅显示分钟 | 缺失值为 —、真实零保留、修复 RFC3339 时区与毫秒解析，长时长显示小时/天 | 避免伪数据和不易读的数值 |
| 英文仍有硬编码中文 | 补齐连接数量、测速超时、启用操作及新增状态翻译 | 中英文一致 |
| 设置开关缺少独立名称 | Row 统一关联标签和说明，保留原生键盘操作和焦点 | 可访问性与自动化识别 |

## 最新卡片方案

右侧保持三张等宽卡片：接管方式 / 连接状态 / 实时速率。删除原配置来源卡片及左侧重复状态组；配置入口保留在顶部。状态卡片为只读信息，标签左对齐、结果右对齐。没有按钮，没有自动网络探测；网络连通性显示「需诊断确认」，提示在顶部诊断查看检查结果，**不展示未经验证的绿色成功状态，也不伪造诊断结果**。

卡片最大高度分别 296 / 148 / 224px，总组最大 700px（含两处16px间隔）。沿用 home-controls 容器高度自适应：579px以下收紧内边距，479px以下缩小行间距。大窗口超过上限的空间留在卡片组下方，小窗口不产生右侧内部滚动条。沿用 App 主题变量和公共按钮。

## 验证

- 前端 TypeScript + Vite 生产构建通过（现有大 chunk 提示仍在）。
- 前端 13 项 Node 测试通过：累计值口径、迟到读取防覆盖、端口校验、缺失值/时长，加既有按钮/国旗/网格测试。
- 后端 lib 测试：118 通过，1 项真实系统代理操作测试按原配置 ignored。需要 CROSSBOW_CORE_BIN 的真实内核用例在未配置时自行跳过执行；这些结果不等同原生端到端验收。
- 浏览器用**生产 App 与生产 CSS**搭配内存 IPC 验证：1120×734 浅色、880×620 深色英文；端口7899失焦应用次数仍为0，明确应用后为1；开关有独立名称；无结果只有一个提示并可重置；切页后收到的累计仍为32MB/12MB。
- 独立验证节点 loading/error/noConfig/stopped；读取失败时首页与底栏显示待确认而非已停止，设置网络区禁用但外观区仍可用。

- 未操作安装版代理、未执行 Windows 原生验收、未新增节点延迟时间戳。

## 重放

安装仓库依赖后，在仓库根目录执行：

```sh
./apps/desktop/node_modules/.bin/vite --config docs/designs/2026-11-03-ui-reliability/v01/vite.config.mts
```

访问 http://127.0.0.1:5208/ 。可加 ?dark=1&en=1、?case=loading、?case=error、?case=noConfig、?case=stopped。底部测试栏仅存在于此模拟预览，不进入正式 App。它使用脱敏示例，不连接真实系统代理。source.zip 保留当次源码及运行夹具，实际截图见 previews/。

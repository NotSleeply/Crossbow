# 官网 V3 主题正式实现

2026-10-28。Issue #176。设计参考 PR #175（Issue #174）的 v03，用户已指定本版组合方式。状态：已实现，待 PR 评审，未合并部署。

## 范围

- 正式源码：apps/site。首页上部采用 V3 白色主题、标题与设备→分流→网络示意图；单条数据包行进 840ms，结束后间隔约 2.56 秒。支持手动暂停、页面隐藏暂停与减少动态效果。
- 首屏下保留用户截图指定的六张功能卡片、双内核介绍、三步上手、两平台下载卡片。全部改为白色/浅灰主题，无应用截图。
- 导航顺序：首页、功能详解、进阶指南、GitHub、下载。前三页和下载为独立 HashRouter 路由，保留现有 GitHub Pages 子路径和 Netlify 兼容能力。移动端折叠菜单，背景 inert；Esc 可关闭，跳转后收起。
- 功能和指南使用相同主题；同步校正 TUN/系统代理互斥、iOS 工程骨架等过期说明。新增节点测速与站点检测说明。
- 下载继续解析 GitHub Releases 的版本与资产。API 未返回、限流、离线或某平台资产缺失时跳到官方 latest 发布页，不回落过期的安装包直链。

## 留存

source.zip 是本次官网可编辑源文件及字体/品牌资源快照（不含 node_modules、dist、未使用的截图资源）。解压后在 apps/site 安装依赖并运行 npm run dev；正式仓库使用其现有 pnpm 工作流。previews 保存实际浏览器渲染；manifest 列出基线、来源、路径和哈希。历史 V1/V2/V3 提案保留在 PR #175，本实现不覆盖旧稿。

# 日志筛选工具栏 v01

状态：已实现，待用户确认。关联 Issue #193。

采用现有 Crossbow 字体与明暗色 token，不更改全局设计。标题 22px，与级别筛选分组留 20px；按钮 32px，搜索/清空 36px。级别按钮以 aria-pressed 表达独立多选，实心圆点和底色表示启用，空心圆点表示关闭；保留 debug 默认关闭，其余启用。

搜索框增加搜索图标、可访问名称，清空使用低强调图标文字按钮，空日志禁用。小于 820px 时搜索和清空换为第二行，小于 460px 收紧级别按钮。所有按钮保留 hover、active 和键盘焦点。

验证：前端生产构建通过；真实 LogsPage 配合脱敏模拟 IPC，在 1440×900 明暗、760×720 和 390×800 截图；页面无横向溢出。Playwright 验证 debug 切换、关键词筛选、info 关闭、清空和空状态禁用，零页面异常。预览采用模拟数据，不连接或修改正在运行的代理。表格正文保留原布局与独立滚动，不属于本次调整范围。

## 文件

- index.html / preview.tsx / preview.css：可编辑设计预览，复用生产组件。
- source/：本版生产组件快照，便于后续比较。
- previews/：实际浏览器渲染的明暗与窄屏 PNG。
- manifest.json：基线、关联记录和文件散列。

仓库根目录启动 Vite（使用 apps/desktop/vite.config.ts），访问本目录 index.html。预览依赖仓库前端依赖；独立冻结效果见 PNG。

# 官网导航、主题与双语 V2

- 状态：已实现，待 PR #260 评审；关联 #261（延续 #259）。
- 基线：官网优化分支 `66197d2`；正式代码：`apps/site/`。
- 用户目标：导航更精致，外观与 App 一致，提供中文/英文切换。
- 技能：emil-design-eng；沿用已确认的白色 V3 和 B1 品牌，不引入截图型营销图片。

## 设计取舍

| Before | After | Why |
| --- | --- | --- |
| 文字链接与两个动作挤在右侧 | 中间集中页面导航，右侧为 GitHub / 外观 / 语言 / 下载 | 页面与工具各有位置，间距更紧凑 |
| 活跃链接只有底线，下载为大描边框 | 活跃页使用安静的浅底，下载为紧凑主按钮 | 减少视觉线条，保留动作层级 |
| 固定白色 | 浅色 / 深色 / 跟随系统 | 直接复用 App 的色彩角色与数值 |
| 只有中文 | 首页、功能、指南、下载、FAQ、页脚与可访问名称中英文成对 | 切换后不留下未翻译的内容页 |

桌面页头 80px；1000px 以下导航折叠为菜单，手机上下载以图标展示，GitHub 移到菜单。380px 以下品牌保留标志，避免挤压工具。手机工具触点至少 44px，外观与语言弹层在窄屏固定于右上方安全边距内。浮层使用 160ms 透明度/轻微位移动效，hover 150ms；减少动态效果时禁用浮层动效。

## 颜色与偏好

颜色直接核对 `apps/desktop/src/index.css`：浅色背景 #ffffff、表面 #f7f8fb、文字 #242b37、强调 #455ab5；深色背景 #1a1c21、表面 #23262d、文字 #e9ebf1、强调 #b7b4ed。深色主按钮使用浅色底与深色字，品牌标志仍保留用户确认的 B 色。

首次外观跟随系统；首次语言按浏览器语言选择中文或英文，其他语言回退英文。明确选择后保存到 `crossbow.site.theme` / `crossbow.site.language`，只影响官网。启动前脚本避免已保存深色时先闪白；存储受限时本次访问仍可切换，后续可监听其他标签页与系统外观的变化。

弹层有明确名称与原生 radio 状态，支持键盘选择、Escape 关闭并恢复触发器焦点、点击外部关闭、焦点离开关闭。切换语言只更新内容、页面标题、描述和 html lang，不重置路由或主动滚回顶部。

## 文案与内容

`messages.ts` 保存成对中英文文案，字面量键通过 TypeScript 检查，`preferences.tsx` 提供统一翻译与主题状态。订阅信息、版本、下载地址不参与翻译。指南代码示例的英文注释仍保留实际中文节点/策略组字面量，使配置示例保持原有匹配逻辑。

保留 V1 的对称连接图、单包传输/间歇动效、原有功能和三步上手卡片、Linux 贡献者及能力边界说明。没有修改 App 或其偏好。

## 留存与复现

`source.zip` 是可编辑、可播放的完整网站原型，包含源码、字体/品牌资源、配置与测试，不含依赖、构建产物或凭据。实际截图在 `previews/`，V1 未覆盖。

解压后在 `apps/site` 执行 `npm install --package-lock=false`，再运行 `npm run dev -- --host 127.0.0.1 --port 5207`，访问 `http://127.0.0.1:5207/Crossbow/`。Node 20.19+ 或 22.12+。顶部外观与语言按钮用于检查全部组合；无需特殊演示参数。

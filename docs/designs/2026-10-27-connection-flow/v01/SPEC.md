# 概览连接路径动效 · v01

日期：2026-10-27。关联 #160。状态：设计提案，尚未接入应用。

## 设计决策

目的为运行状态提示，保留「这台电脑 → 规则分流 → 当前节点」现有结构、图标和文字。只在两段细线上增加蓝紫色短数据包；图标、标签和延迟数值不移动。中间节点用极淡的一圈线条响应经过，不使用扩散光晕、弹跳或整页入场。

| 项目 | v01 参数 |
| --- | --- |
| 单轮 | 2800 ms |
| 第一段前进 | 0–36%，线性匀速 |
| 路由处停留 | 36–44%，约 224 ms |
| 第二段前进 | 44–80%，线性匀速 |
| 错开下一包 | 1400 ms，同一条线上最多一个主要数据包 |
| 数据包头部 | 7×4 px，蓝紫色，2 px 圆角 |
| 尾部 | 28×2 px，22% 不透明度，不使用模糊 |
| 连接线 | 1 px，沿用主题灰线与箭头 |
| 中间响应 | 1 px 圆环，最高 32% 不透明度；图标本身不缩放 |

移动只使用 transform / opacity，CSS keyframes，不新增动画依赖；循环采用 linear，因为表示持续传输。按钮反馈沿用短 ease-out，120–160 ms。动画层 aria-hidden，不逐帧播报。

## 实现时的真实状态边界

- 仅在内核运行、当前接管路径有效且收到近期正流量时显示流动。设计中的包是「有数据经过」的符号，不是实际网络包、带宽刻度或分段耗时。
- 已连接但无流量：静态轨道；没有近期流量事件时不能永久播放假数据。
- 断开：灰色静态路径，延迟展示 —。异常：停止传输并按真实错误标记，不用某站点 403 推断整个隧道死亡。
- 页面隐藏或离开概览时暂停；恢复只反映最新真实状态。无需为该动效增加后台高频轮询。
- 系统或手动减少动态效果：无位移与圆环动画，以静态主题色路径和状态文案表达。演示可暂停，状态和文字仍可阅读。

## 验收

查看左到右连续性、中间接力、文字稳定、明暗主题对比、短宽窗口溢出、暂停、减少动态效果和四种状态。模拟数据仅存在于设计稿，不读取用户节点、订阅或代理状态。

本稿属于产品内局部状态动效，不是宣传片；因此不加入整页空场、入场或溶解退场，不以宣传视频替代交互原型。用户确认方向后再独立实现正式组件。

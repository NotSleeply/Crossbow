## 本次调整

用户指出 v02 的循环间隔过短，希望每条数据传输后等待 2–3 秒。本版保持单条快速贯穿，延长抵达后的等待；v01、v02 原样保留。

## 动效规格

- 全路径只有 **一个移动元素**；同一时刻最多一个数据包头部。
- 一轮 3400 ms：前 840 ms 匀速从左到右，后 2560 ms 留白；不在中间停留，不反向，不同时启动第二包。
- 数据包头部 7×4 px，尾迹 36×2 px / 22% 不透明度。沿用主题蓝紫色。
- 两条灰色轨道和三组图文不动。运动层跨越整段路径；中间文字区域遮罩，数据经过时短暂遮挡，不穿过文字。
- CSS 只动画 transform 与 opacity，linear，无动画依赖。遮罩随布局断点适配，不逐帧测量 DOM。
- 仅运行且近期存在真实流量时播放；空闲、未连接、异常静态。演示状态是模拟数据，不读取内核。
- 支持暂停、后台暂停和系统/手动减少动态效果；减少动态效果时用静态主题色路径。

## 待确认

体验重点：只看到一个数据包快速从左到右，经过中部不会有另一个点同时出现。宽/窄屏都保持单一方向和稳定文字。设计稿确认后另行接入正式组件。

## 交互与边界

- 使用既有主题、Dialog、Button、Select、ProgressRing 和统一 Notification。危险恢复操作有范围说明与确认，恢复前仍生成现有写前快照。
- 日志导出走原生保存对话框；最多 2000 条 / 总输入 4MiB，单条脱敏输出按现有 redact 上限8000字；取消保存不报告成功。只导出当前筛选结果，而非隐藏过滤掉的行。
- 节点摘要是原始订阅 proxies 按唯一 name 比较；不支持比较时显示未知，不能把未知当成零变更。重试时间为当前进程调度器实际记录；重启后重新进入调度周期。
- 快照 id 只能匹配 Store 返回的现有文件名，禁止任意路径读写。恢复不尝试修改系统代理/TUN权限；运行配置变动由原事务处理。
- 恢复和导出防止重复点击；诊断回调以本次 runId 过滤，卸载后不再更新旧页面。
- 技术明细沿用后端原文；界面操作、状态、时间标签支持中英文。测试数据均为示例。

## 验证记录

生产 TypeScript/Vite 构建；前端22项测试；桌面 Rust lib 测试及 crossbow-core 50项测试。最终实际计数以 previews/checks.json 为准。真实系统代理测试继续 ignored，未配置真实内核的条件用例不会运行真实代理。

浏览器验证生产 App + 内存 IPC：诊断逐步/完成/跳过/首个问题、连接完整复制并恢复原剪贴板、日志暂停/返回底部、订阅错误信息、恢复确认及模拟恢复、通知定位混合端口、站点 HTTP403解释与时间/出口。截图保存在 previews/。

没有运行安装版的代理、没有对用户真实配置执行恢复、没有以真实日志导出文件；原生保存对话框与真实恢复最终需安装验收。本预览仅内存模拟，不构成这些原生验收。

## 重放

仓库安装依赖后：

```sh
./apps/desktop/node_modules/.bin/vite --config docs/designs/2026-11-03-workflows/v01/vite.config.mts
```

打开 http://127.0.0.1:5209/，深色英文为 ?dark=1&en=1。诊断示例会在代理测试项失败、系统代理项跳过；恢复为模拟操作，导出模拟取消。源码快照见 source.zip。

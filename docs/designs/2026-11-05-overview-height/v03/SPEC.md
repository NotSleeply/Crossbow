# 概览 V03 · 图表与段间距同步伸缩

关联 #318。用户在 v0.13.5 的最小窗口和稍大窗口中看到图表偏高。最小窗口也要有明确留白，路径图标保持同一尺寸。

| 部位 | 高度规则 |
| --- | --- |
| 路径图标 | 32px。按高度切换时保持尺寸 |
| 状态到路径、路径到操作 | 各 18–72px |
| 操作到图表 | 14–24px |
| 图表整体 | 120–200px，含标题、绘图区和时间轴 |

先容纳状态、路径与按钮的自然高度，再预留各项最小值。剩余空间按权重同时分给图表和三处间距，达到上限的项目让出份额。空间过多时留在底部，左侧高度上限 700px。左侧内容密度按宽度适配，避免只改变高度时路径整体跳大。更新提示或长文案放不下时沿用整页滚动。

## 预览

在仓库根目录执行：

```sh
node apps/desktop/node_modules/vite/bin/vite.js --config docs/designs/2026-11-05-overview-height/v03/vite.config.mts
```

访问 [尺寸矩阵](http://127.0.0.1:5221/matrix.html)。矩阵复用 V02 的生产组件预览与模拟 Tauri 边界，底部标签显示实际 DOM 高度和段间距。包含同宽 880×560、880×600、880×640，用于比较渐进伸缩。截图二以原始 1948×1398 按 2× 换算为 974×699，作为尺寸参考。另有更新提示、深色英文和大窗口。

桌面与预览构建、HTTP 入口、差异检查通过。浏览器控制连接超时，截图、实际拖动窗口与原生验收待补。

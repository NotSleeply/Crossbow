# 概览左侧高度分配 v01

日期：2026-11-05。Issue #295。状态：实现完成，本地构建通过；实际视觉验收待补。

## 目标与原因

用户在 v0.13.2 小窗口中发现，标题与路径、路径与按钮之间留白很大，图表被挤在页面底部。旧规则同时使用了 `space-between`、按可用高度占比的路径区，以及短窗口 96px 图表；此前只收紧按钮/图表间距，未消除这些冲突。

| Before | After | Why |
| --- | --- | --- |
| 左侧用 space-between 撑开段间距 | 三行 Grid：状态、路径自然高度，最后一行使用余量 | 空白不再竞争图表空间 |
| 路径按 28cqh 占高，内部再居中 | 路径按标题、图标、文字的实际内容高度排列 | 小窗口不用预留一大块空白 |
| 小窗口强制图表 96px | 图表使用剩余高度，132px 下限、300px 上限 | 优先保留趋势与刻度的可读性 |
| 留白随容器无限扩大 | 段间距 12–24px；短窗口固定 12px | 小窗紧凑，常规窗适度舒展 |
| 高度变化影响按钮/图表关系 | 两者仍为同一组，间距常规 12px、短窗 8px | 主要操作与趋势保持邻近 |
| 状态文字变长时挤压关系不明确 | 状态行自然增高；极端高度不足由既有整页滚动承接 | 不裁切状态说明，也不继续压薄图表 |

整体仍以 700px 为上限。图表达到 300px 后，多余空间留在图表下方；超过整体上限后空白留在整个左侧内容下方。右侧三张卡片的规则保持现有实现。删去 index.css 和 Layout.css 中旧的冲突尺寸规则，当前标准同步写入 docs/UI-DESIGN.md。

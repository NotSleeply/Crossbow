# 概览左侧 · 最小间距与渐进留白 V02

状态：按用户最新反馈实现；真实窗口视觉验收待补。关联 #307。

## 目标

小窗口时，状态、连接路径、操作之间有最小间距，余量给图表；高度足够后逐渐拉开两处间距，不能把所有新增高度都用于放大趋势图。本版替代 V01 的空间分配规则。

| Before | After | Why |
| --- | --- | --- |
| 段间距仅 12–24px，新增高度主要进入图表 | 两处弹性留白各 12–72px，图表整体 132–220px | 高窗口保持呼吸感，趋势图不再成为页面视觉主体 |
| 底部独立 Grid 填满余量 | 底部无语义包装 display:contents，操作与图表参与整个左侧的 Flex 高度预算 | 长状态说明、按钮换行和更新提示都以实际内容高度参与分配 |
| 按视口高度估算段间距 | 空间紧张时，间距退回 12px，图表在剩余空间中伸缩；图表达 220px 后余量进入间距 | 缩小时不让空隙挤压图表，增高时不会把图表无限拉长 |

状态和路径保持自然高度。两处纯装饰伪元素分配弹性留白，无额外可聚焦内容；视觉顺序与 DOM 阅读顺序一致。操作与图表间距常规 12px、紧凑模式 8px。图表最大高度包括标题、绘图区和时间轴。间距和图表均达到上限后，额外高度保留在底部；左侧总高度最多 700px。极端短窗/长内容超过最低需求时使用已有整页滚动，避免控件或图表互相覆盖。

右侧卡片、主题、连接动画、状态与代理生命周期均未改动。没有新增尺寸动画。

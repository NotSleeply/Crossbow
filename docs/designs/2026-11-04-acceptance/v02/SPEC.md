## 关键交互与边界

- 筛选：多选 ChoiceChip，有 aria-pressed 和勾选；日志及节点“仅看可用”复用。选中背景为主题 accent 的 12% 混合。
- 分段：单选 radiogroup，指针滑动 160ms，键盘操作立即切换，减少动效偏好关闭位移动画。
- 开关：默认 34×20 / 圆点14，紧凑 28×16 / 圆点10；仅键盘显示外焦点环，过渡 140ms。
- 日志：不换行，搜索可缩至 70px；1100px 以下导出/清空只显示图标且保留可访问名称，筛选隐藏辅助色点但保留勾选和文字。
- 覆写：新建名称为空/提交中不可提交；使用同步 ref 防重复创建；失败保留对话框和输入，由统一 Notification 报告。取消、Escape、遮罩点击关闭；提交中不关闭。
- 节点：卡片模式的底部锚点只在空间充足时分配空余；内容超过视口时 margin 自动退至零，保留单一工作区滚动。
- 滚动检查范围：设置、节点、诊断、配置详情和侧栏；连接表格已有 12px 行内边距、日志复制操作已有 48px 留白、代码编辑器已有 14px 内边距，保持已有间隔，避免重复叠加。
- 未改变自动选择策略，未给真实节点手动固定；本轮不发版、不改应用版本号。

## 预览与留存

`previews/` 是实际生产组件使用脱敏模拟数据渲染的截图：日志单行、卡片底部及覆写布局，1120×720。更早的深色/880px迭代保存在 v01，不作为 v02 最终小窗截图。

`source.zip` 是当前完整可编辑前端、后端源码及构建清单快照；包括本版原型。运行中的导入路径随当前工作区变化，以 zip 为冻结版本依据。解压到独立目录，安装仓库依赖后，在 apps/desktop 运行：

```sh
npm exec vite -- --config ../../docs/designs/2026-11-04-acceptance/v02/vite.config.mts
```

打开 http://127.0.0.1:5212/ 。可用 `?dark=1&en=1`、`?many=1`、`?pass=1`，以及页脚 loading/error/stopped/noConfig 脱敏场景。原型含可播放的共享控件过渡与连接传输动效，不访问真实 Tauri 配置。

## 交互与尺寸

- 端口阅读态宽度随数值及按钮自然变化；编辑区域最多占行宽 50%，输入宽度 76px，操作间距 8px。数值使用等宽数字。
- 修改后才进入编辑；输入自动聚焦。Enter 显式应用，Escape/取消恢复后端当前端口；失焦不保存。原有 1024–65535 校验、操作中禁用与统一错误通知保留。
- 成功应用后回到阅读态，取消/成功后焦点返回修改按钮；失败保留输入供修正。通知定位先滚动端口行，再聚焦修改按钮。
- 节点卡片保留搜索、地区/延迟筛选、单节点/批量测速、选中态、自动选择恢复以及分页。最多四列/四行，少量节点使用自然高度。
- 连通性测试在节点工作区底部，有溢出时正常滚动，结果中的时间/出口/路径变化提醒保留。
- 明暗颜色均复用应用主题变量，本次不增加动画或新视觉组件。

## 可编辑源稿与原型

source.zip 保存本提交前端源码、构建清单和本版原型。zip 为冻结版本；工作区内原型直接导入生产组件，会随源码变化。

解压到独立目录、安装依赖后，在 apps/desktop 运行：

```sh
npm exec vite -- --config ../../docs/designs/2026-11-04-ui-simplification/v01/vite.config.mts
```

打开 http://127.0.0.1:5213/ 。支持 `?dark=1&en=1`、`?many=1` 及页脚加载/错误/停止/无配置场景。脱敏 mock 记录端口提交次数，方便验证失焦/取消不会写入真实设置。

# 更新信息条精简 V4

- 日期：2026-10-29
- 状态：已实现，更新 PR #190；Refs #189
- 输入：用户认为首页更新提示过厚，要求降低高度、精致化。
- 设计指导：沿用 emil-design-eng 的弱化辅助信息与稳定布局原则。

## 调整

| Before | After | Why |
| --- | --- | --- |
| 常规46px、低窗34px，两套高度 | 全部统一32px | 减少对概览正文的挤压，避免高度跳变 |
| 26px带底色图标块 | 16px线性图标或进度环，无底块 | 提示的层级低于连接状态 |
| 有底色的版本徽标 | 11px灰色版本文本 | 减少嵌套色块和视觉重量 |
| 10px圆角、大块内边距 | 7px圆角、6px上下内边距 | 保持现有表面色与边线，更接近信息条 |

保留整个信息条的点击区域、右侧操作文字、hover与键盘focus样式；不修改更新检测、下载或安装逻辑。长版本号单行省略并可查看完整标题；下载进度数值继续显示。

## 验证与归档

- 前端构建通过。
- 实际正式组件的“发现更新 / 下载中 / 安装就绪”三种状态均为32px，中英文及深色验证无横向溢出。
- 首页实际880×560与1120×734验证通过，无整页或侧栏溢出。
- `previews/` 保存实际截图及状态尺寸，`source.zip` 保存当前正式CSS、UpdateBanner、ProgressRing源文件快照。V1/V2/V3保留，不覆盖原稿。

首页预览沿用V3的模拟Tauri边界（5199）。本版附带三状态开发校验页：

```sh
node apps/desktop/node_modules/vite/bin/vite.js --config docs/designs/2026-10-29-overview-sidebar/v04/vite.config.mts
```

打开5200端口，参数`en=1&dark=1`切换英文深色。此页只渲染正式组件与模拟状态，点击不会下载或安装。正式应用仍使用原有设置入口。

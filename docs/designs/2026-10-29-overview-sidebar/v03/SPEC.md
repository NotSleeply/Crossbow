## 正式实现

- `apps/desktop/src/pages/Home.tsx`：状态 → 连接路径 → 常用操作 → 趋势；右侧接管方式 → 配置 → 实时速率。复用原有 IPC、状态回读、通知、订阅与 ConnectionFlow 动效。
- `apps/desktop/src/index.css`：清理旧首页布局和响应式覆盖；宽度决定列布局，实际可用高度决定密度。短窗的更新条紧凑展示。
- `apps/desktop/src/i18n.ts`：补充中英双语标签与状态提示。

### 与 V2 原稿的差异

1. 三节点中心从16.7% / 50% / 83.3%调整到14.7% / 50% / 85.3%，减少两端留白。线段位置同步计算，保留单个数据包、840ms传输和2560ms间隔。
2. 右侧按内容确定最小高度，再向每卡上限增长：接管296px、配置76px、速率224px。常规间距16px，整组最高628px；紧凑间距12/8px，极限高度6px。可用高度超出上限后才留下组外空白。
3. 左侧按真实可用高度收紧，而不是只看窗口高度；保留更新条和原生标题栏占用空间后的预算。
4. 趋势保持原有120秒历史及曲线，补充同尺度刻度、图例、时间标签。大刻度用紧凑数值格式，防止数字越界。
5. 开关下说明在极限布局收起，仍可通过原生 details/summary 查看，支持键盘及Esc。

## 可复现预览

先安装仓库现有依赖，在根目录执行：

```sh
node apps/desktop/node_modules/vite/bin/vite.js --config docs/designs/2026-10-29-overview-sidebar/v03/vite.config.mts
```

打开 `http://127.0.0.1:5199/`。参数可组合：`banner=1` 更新条、`stress=1` 长名称大数值、`en=1` 英文、`dark=1` 深色、`empty=1` 无配置、`windows=1` Windows框架。

此原型直接导入正式HomePage、ConnectionFlow、IPC包装及CSS，只在Vite配置中替换Tauri边界。所有状态和数值是明确标注的模拟数据；没有真实系统代理、TUN或网络操作，也不会打包进应用。此配置只供开发预览。

`previews/` 保存真实浏览器截图及测量，`source.zip` 保存当次正式前端源文件快照；后续主代码改变时仍可追溯本版。V1/V2原稿保留不覆盖。超出支持的最小窗口或文字放大时，使用整个页面滚动兜底，不能遮挡控件或给右侧加嵌套滚动。

## 范围与信息层级

不修改正式应用。原型保留现有主题与导航，重新组织左侧内容；右侧完整沿用 V1 自然高度方案。

屏幕的首要问题：当前是否接管了网络、按什么规则、通过哪个出口？左侧承担状态和路径，右侧承担控制及精确速率数据。

1. **连接状态**：运行标识与内核名称 → 当前接管方式 → 一句状态解释。不重复右侧配置名称。
2. **连接路径**：电脑 → 规则 → 节点，三个等宽区域；图标、名称、辅助信息各自对齐。连接线穿过图标中心，在图标处留白；细箭头表示向右的方向。
3. **常用操作**：选择节点、查看连接，紧接路径下方，固定顺序。
4. **流量趋势**：保留在底部，限制高度；加入下载/上传图例、时间范围和刻度。精确实时速率仍由右侧卡片承担。

品牌与主题使用已有灰白表面、靛蓝数据线、系统字体；不新增装饰图标背景、阴影或渐变。页面独有视觉是三段连接路径。

## 多尺寸规则

- 页面仍为“主信息 + 右侧控制”双列，右侧300–368px；不通过横向拉大卡片来填满窗口。
- 左侧采用纵向内容流：状态、连接路径、操作、趋势；区域间距常规20px，小宽16px，低高12px。
- 路径三个节点固定等分，长节点名在本节点内省略，完整名称通过提示查看，不让连接线与文字互相挤占。
- 常规路径图标32px；低高28px。只改整组密度，不单独挤压某一块。
- 趋势常规132–186px；窗口高度≤650px时112px。路径在低高时最低104px，仍保留三层信息。
- 右侧规则与 V1 相同：宽度决定列几何，高度决定密度，数据列结构固定。
- 最小880×560并带更新提示时：内容区354px，左侧与布局底线一致，右侧卡组349px。没有裁切、局部滚动或数值溢出。
- 超出桌面支持边界（低于最小尺寸、辅助字体放大、多条额外内容）应允许整页滚动兜底，不继续缩字或遮挡。

## 交互和状态

- 尺寸按钮可切换四档，预览画布保持目标CSS尺寸，再按可视宽度缩放显示。
- 可切换更新提示、长名称/大数值、深色。
- 两个演示开关独立切换，左侧状态随之更新；都关闭时显示未接管。
- 帮助按钮显示被收起的说明，Esc关闭。其他业务入口仅提示这是原型。
- 本版只调整布局，不添加新的动效或修改已有正式连接动效。

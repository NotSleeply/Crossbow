# Crossbow 桌面界面整理 v01

日期：2026-11-04。状态：已实现，待 PR 评审。关联 #275；前置功能 PR #276。
基线：main 2c3add3 + 工作流提交 333cf87。保留用户确认的 B1 标志、App 明暗主题和右侧连接状态卡片。

## 判断与方向

采用 emil-design-eng 的克制交互原则与 design-taste-frontend 的应用界面流程。方向为 Framed sheet，方向抽取见 direction/；保留现有字体、品牌靛蓝与浅色框架，不为追求新鲜更换已确认的视觉语言。方向脚本记录的机器日期为 11 月 3 日，本次归档按用户环境日期 11 月 4 日。

界面需要回答：概览——连接是否受管、下一步做什么？节点——当前出口是什么、如何快速选择？设置——修改影响是什么、在哪里维护？

数据清单：内核状态与读取可信度；系统代理/TUN 开关；当前配置与多个可切换配置；实际出口和路由；实时流量与累计计数；策略组名称与类型；节点协议/延迟/可用性；筛选结果和空态；站点测试上下文；平台能力；设置应用与重启影响；维护入口。

## 交互边界

- 配置切换以真实后端成功为准；同操作只发错误通知，不乐观改当前配置。成功刷新概览/节点与顶栏。
- 输入框是弹性宽度和最大宽度，不写死节点搜索宽度；筛选工具栏不换行。
- 帮助与配置浮层采用已有 Base UI，支持 Escape、外部点击与焦点返回。指针过渡 160ms，键盘打开和 reduced-motion 即时。
- 卡片不拉伸；列表每行 44px，卡片 76px，大量结果使用已有分页。窗口过小时整个工作区自然滚动，避免裁掉站点工具。
- 实际桌面窗口最小 880×560（Tauri 原生限制）；验证 880、1120、1440 与明暗/中英，不虚构手机 App。
- 通过 CUA 实际浏览器截图与只读 DOM 检查代替 skill 的外部 CDP inspector，遵守本会话浏览器工具限制。

## 实测结果

- TypeScript/Vite 生产构建通过；24 项前端测试通过，包含不同宽度/数量的自然高度与分页边界。既有超过 500kB bundle 提醒仍在。
- CUA 验证：880×560 明暗中英、1120×720、1440×1000；最小窗口无横向溢出，右栏实际 overflow 为 0，策略组行高 48px，筛选项中心在同一行。
- 搜索内层 border=0、outline-style=none、shadow=none，焦点只在外层；策略组搜索不改变已选组，节点空态可重置。
- 显示密度跨刷新保留；配置用键盘切换成功后顶栏同步，模拟失败保持原选择；Escape 返回触发器。
- 站点测试四组时间/出口在收起展开后完全保留；设置所有开关有名称与说明关联，小窗设置说明可读并自然滚动。
- 设计 lint（新增控件与布局）0 FAIL / 7 WARN，均为输入焦点环、开关内描边和真实浮层阴影；这些为功能边界，不是卡片装饰。
- reduced-motion 路径通过样式审查；未切换操作系统减弱动态效果设置。原生代理、权限、安装包不在本次纯前端验证范围。
- 开发过程中修改预览 IPC 模拟模块触发过一次热更新的 Portal 移除错误，完整重载后正常；正式交互复测不依赖热更新。

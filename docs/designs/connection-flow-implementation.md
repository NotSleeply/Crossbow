# 概览连接路径 v03 实现记录

日期：2026-10-28。实现 issue #166，设计稿 PR #165。用户已确认 v03。

- 正式组件：`apps/desktop/src/components/ConnectionFlow.tsx`。
- 概览页提供已存在的实际 traffic 事件与运行/接管状态，无新后端轮询。
- 单一数据包，840 ms 从左到右，抵达后等待 2560 ms，周期 3400 ms；文字和图标不动。
- 仅 Running、接管已开启、有当前出口信息且最近 4 秒收到正流量时播放；短暂零流量不反复重启动画，事件停止后自动过期。
- 流量头为状态示意，不代表真实包数量、吞吐量比例或两段连接耗时。不会用某次节点测速失败推断整条链路异常。
- 通过 ResizeObserver 仅在布局变化时计算轨道位置与中间文字遮罩；动画只使用 transform / opacity，无逐帧 DOM 测量。
- 页面隐藏暂停；组件卸载清理监听、超时和 observer；系统减少动态效果时改为静态主题色连线。
- 设计稿 v01–v03 源文件、规格和截图由 #165 归档，本文件补充正式实现位置，不覆盖历史设计稿。
